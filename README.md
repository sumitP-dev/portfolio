# Sumit Patanwal — Portfolio

Personal portfolio site: frontend & AI-augmented engineer (React Native, React.js, fintech).

Plain HTML/CSS/JS — no build step. Animations use [GSAP](https://gsap.com) and smooth scrolling uses [Lenis](https://lenis.darkroom.engineering), both loaded from a CDN.

Run locally by opening `index.html` in a browser. Hosted on GitHub Pages.
